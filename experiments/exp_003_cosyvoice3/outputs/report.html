6. 核心发现

假设验证: 多说话人 LoRA (Tier 1) 可以在不损害说话人保真度的前提下改善韵律精度。

证据:
  • SECS 保持 0.945 (完全不变) — 说话人身份未被 LoRA "冲淡"
  • F0 RMSE 下降 23 Hz (97→74) — 韵律跟随更接近 reference
  • rank=8 (仅 1.08M 参数) 达到最优 — 小容量足以捕获跨 emotion 的风格迁移
意义: 这验证了 RESEARCH_PLAN 的双层 LoRA 架构的 Tier 1 层设计。 下一步: Tier 2 (单说话人 avatar LoRA) + Composition (Tier1 + Tier2 叠加)。
