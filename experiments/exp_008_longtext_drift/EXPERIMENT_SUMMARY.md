# exp_008: CV3 长文本注意力漂移实验

**日期**: 2026-05-30  
**优先级**: P3 (研究计划 问题 B: 维度 2 × 3)  
**设备**: H800 (81 GB VRAM)  
**运行时间**: 11 分钟  

---

## 1. 假设

CV3 的韵律一致性（prosody + 说话人身份）随文本长度递减，训练时 `token_max_length=200 chars`，超过此长度可能出现相变式退化。

## 2. 实验设计

- **Ref**: 0002/Neutral, ESD 中文语料
- **分段长度**: 50 / 100 / 200 / 400 / 800 / 1600 / 3200 chars + 全文本 (4556 chars)
- **指标**: CER (FunASR paraformer-zh), SECS (WavLM speaker embedding), 语速 (chars/sec), RTF

## 3. 结果

### 3.1 分段合成指标

| 文本长度 | CER | SECS | 时长(s) | RTF | 语速(cps) |
|----------|------|------|---------|------|-----------|
| 50 | 0.028 | 0.971 | 9.4 | 0.4 | 5.3 |
| 100 | 0.080 | 0.962 | 15.4 | 0.34 | 5.5 |
| 200 | 0.118 | 0.974 | 29.5 | 0.33 | 5.7 |
| **400** | **0.147** | **0.971** | 55.4 | 0.35 | **6.0** |
| **800** | **0.919** | 0.969 | 69.5 | 0.38 | **9.8** |
| 1600 | 1.000 | 0.962 | 165.4 | 0.5 | 8.4 |
| 3200 | 1.000 | 0.000 | 244.9 | 0.7 | 11.3 |
| 4556 (全文本) | ERROR | — | — | — | — |

### 3.2 全文本合成失败

```
ERROR: The expanded size of the tensor (15000) must match 
the existing size (15246) at non-singleton dimension
```

CV3 内部 speech token 序列长度推算在超长文本时产生维度不匹配，张量无法对齐，直接报错。

### 3.3 关键观察

1. **CER 相变**: 400→800 chars 区间，CER 从 0.147 跳变到 0.919（6.3× 恶化）
2. **SECS 崩塌**: 3200 chars 处说话人身份完全丢失 (SECS = 0.000)
3. **语速异常**: 随文本增长，语速从 5.3 cps 加速到 11.3 cps（2.1×）
4. **全文本不可合成**: 4556 chars 触发张量维度错误

## 4. 结论

**CV3 无法处理超过 400 chars 的连续文本。退化为相变式，非渐进式。**

| 文本区间 | CER 范围 | 工程建议 |
|----------|----------|----------|
| ≤200 chars | 0.03–0.12 | 安全，训练域内 |
| 200–400 chars | ~0.15 | 可接受，质量轻微下降 |
| 400–800 chars | 0.15→0.92 | **相变区，不可用** |
| 800+ chars | ≥0.92 | 不可用 |
| 4556 chars | 张量崩溃 | 无法合成 |

## 5. 工程策略

**长文本切割为 300–400 chars 段，逐段合成后拼接。**

理由：
- SECS 在 0–1600 chars 保持 0.96+，同 ref 锚定保证身份一致
- 故事/播客内容段间独立性高，段边界与自然停顿对齐
- 无 real-time 要求，离线拼接无延迟约束
- 容错性好：单段失败只需重录该段

切分规则：
- 优先在句号/段落结尾切断
- 不在 `[breath]` 等副语言 token 中间切断
- 每段保持 300–400 chars（以完整句子为粒度）
